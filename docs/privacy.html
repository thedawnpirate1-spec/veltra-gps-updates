Privacy Policy

Last updated: 20 November 2026

2. The app works locally

No telemetry, no analytics, no advertising, no user account. Input from keyboard, mouse, joystick or controller is processed in memory only and is never stored or sent.

3. Data stored on your PC

In the folder %APPDATA%\VELTRA-GPS:

  • Profiles and settings (key mapping, deadzones, calibration).
  • Log files for troubleshooting. Your Windows user folder is written as %USERPROFILE%. Logs are deleted automatically after 14 days.
  • The licence: licence key and activation ID, encrypted with Windows DPAPI (readable only by your Windows user).
  • While tweaks are active, the previous Windows values so they can be restored exactly – for "Throttle background apps", for example, process ID, name and priority of the throttled apps and the location of OneDrive. These entries are deleted when the app stops.
  • The control center keeps a local memory (brain.json): which settings were changed and when, the hardware values last seen and the result of the last network test.

None of this leaves your PC. You can delete it at any time in the app under "Profiles and settings → Delete all data".

The maintenance pause also creates two tasks under "\DP HUB" in the Windows Task Scheduler and notes under HKEY_LOCAL_MACHINE\SOFTWARE\DP HUB which tasks and services it has paused. Both are removed when you switch "Pause maintenance tasks while playing" off. If you switch "Network throttling off" on, the previous Windows value is kept under HKEY_LOCAL_MACHINE\SOFTWARE\DP HUB\Original so it can be restored exactly.

4. Hardware display and restart into BIOS

The hardware display reads memory (speed, module name), mainboard maker, GPU setting as well as Secure Boot, TPM, boot mode, drive type and BitLocker status locally only. The values last seen and your confirmation of the hardware are stored locally in %APPDATA%\VELTRA-GPS (brain.json, settings.json, logs). This information is not sent anywhere.

If you click "Restart into BIOS", VELTRA GPS runs the Windows command "shutdown /r /fw /t 30" after your confirmation and a Windows admin prompt. No BIOS settings are changed.

5. Purchase and licence check

Test versions have no purchase; you receive the licence key directly from us, and Stripe is not used.

Purchases are processed by Stripe as Merchant of Record (Stripe Managed Payments). Stripe processes order and payment data under its own privacy policy. Licence keys are issued and checked by Keygen (keygen.sh): on activation and at most once a day, when internet is available, the app sends to Keygen's licence API (api.keygen.sh) the licence key, a pseudonymous device fingerprint and device name (for example "PC-1A2B3C4D"; hashes that contain neither user nor computer name) and the activation ID. The server also sees your IP address and the time. Purpose: checking that the licence is valid (Art. 6(1)(b) GDPR). Both providers are based in the USA; transfers rely on the EU-US Data Privacy Framework or EU standard contractual clauses (Art. 45/46 GDPR).

6. Network test

Only when you click "Test network": 20 pings each to your router, 1.1.1.1 (Cloudflare) and 8.8.8.8 (Google). No data about you is sent; those services see your IP address and the time, as with any ping.

7. Installation through the Microsoft Store

If you get the app from the Microsoft Store, Microsoft handles download, installation and updates under its own responsibility; Microsoft's privacy statement applies.

8. Update check (only when switched on)

The app can fetch a public file with the latest version number at start. No licence or device data is sent; the server only sees your IP address and the time. You can switch this off in the app.
