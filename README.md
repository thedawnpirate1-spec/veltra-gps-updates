# VELTRA GPS – updates

This repository only announces new versions of VELTRA GPS. It contains no source code.

The app reads [latest.json](latest.json) to find out whether a newer version exists:

```json
{ "version": "1.1.0", "url": "https://github.com/thedawnpirate1-spec/veltra-gps-updates/releases" }
```

- `version`: the newest released version.
- `url`: where the player gets it.

Downloads are attached to the [releases](https://github.com/thedawnpirate1-spec/veltra-gps-updates/releases) of this repository.
